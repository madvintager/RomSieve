Your ROM collection, sorted.

RomSieve checks your games against their DAT, keeps the best release of each one in your languages, and rebuilds a clean folder tree. You see every move before a single file is touched.

Every preservation standard

RomSieve reads the DATs of the preservation groups and understands the names of their files, down to the last tag.

TOSEC

Vintage computers

Amiga, Atari ST, Amstrad CPC, C64, ZX Spectrum… The whole naming convention is read: publisher, year, countries, languages, disks and dump flags.

No-Intro

Cartridge consoles

NES, SNES, Mega Drive, Game Boy, GBA, N64… Regions, revisions, betas and demos, parent and clone releases.

Redump

Optical media

PlayStation, Saturn, Dreamcast, Amiga CD32… .cue, .gdi and .ccd sets stay with their tracks, CHD files included.

MAME

Arcade and software lists

Non-merged or merged sets, one archive per machine with the BIOS and devices it needs, and the software of MAME software lists.

See everything before anything moves

A simulation fills a table with every file: kept, excluded, duplicate or non-conforming, why, and where it will go.

  • Search, filter by status, group the releases of each game.
  • Right-click a game to keep another release.
  • Uncheck games to sort only a part of the collection.

One game, one ROM, your way

Among all the releases of a game, RomSieve keeps the best one for you: your languages and countries first, then the video standard, dump quality, complete disk sets, version and revision.

  • Reorder the criteria as you like.
  • France, Europe, USA and Japan presets in one click.
  • The same collection always gives the same result.

Folders the way you want them

Copy, move, create hard or symbolic links, or write one TorrentZip archive per game, into folders such as {publisher}/{title}/ or {country}/{title}/, with a live preview of the pattern.

  • Multi-disk sets completed from other dumps, with .m3u playlists.
  • A whole DAT pack in one pass, each DAT in its own folder.

Safe by design

Your files are never deleted behind your back, and the last sort can always be taken back.

  • Every real sort is logged, and the last one can be undone.
  • Purging a destination deletes nothing: its content is set aside in _purged/.
  • A cancelled transfer leaves no partial file behind.
  • Files that match nothing go to _unmatched/, never lost.
  • A destination that overlaps the source is refused, even through a link.
  • Nothing is ever written outside the destination.

And also

  • Files identified by size and CRC32 (SHA-1 optional), even badly named ones.
  • ZIP, 7z and RAR archives read without extraction.
  • DATs read straight from their ZIP, 7z or RAR archive.
  • Miss lists, fixdats, JSON and CSV reports.
  • Configuration profiles and a CRC cache.
  • Light and dark themes; English, French and Spanish.
$ romsieve-cli run --profile "Amiga 1G1R"
$ romsieve-cli run --dat ~/dats/No-Intro --dat-recursive --execute
$ romsieve-cli undo --yes

The command line, romsieve-cli, runs the same sort with the same safeguards, for scripts and servers. It only simulates unless --execute is given.

Get started

Download the archive for your system, extract it anywhere and run RomSieve. The user guide walks you through your first sort.

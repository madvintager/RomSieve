# Readme extracts

Lines copied from the readme of real patches, reduced to what names their ROM: no credits, no long texts, no patch
and no ROM. `PatchReadmeNameTests` puts each one next to a synthetic IPS, against synthetic ROMs that carry the names
of the DAT entries they cite.

| File | Source | What it shows |
|---|---|---|
| `ff3-maeson.txt` | Final Fantasy III Maeson 2.11 | A No-Intro name with its extension on its own line, then two CRC32 (an old iNES 1.0 header, in no current DAT) |
| `super-doki-bros.txt` | Super Doki Bros (SMB2 Hack) | A No-Intro name with its extension, in quotes, inside a sentence; no CRC32 |
| `zelda2-redux.txt` | Zelda 2 Redux | A No-Intro name with its extension after a parenthesis, followed by an MD5 (not read) |
| `beatles-pepperland.txt` | The Beatles Adventures In Pepperland | A GoodTools name, which names no entry of a No-Intro DAT |
| `smim.txt` | Super Mario Impossible Mode (a BPS, whose readme is never read) | A name close to a No-Intro one (`Bros` without its dot), which names none |
| `rmex-romhacking.txt` | The *ROM / ISO Information* block of the page of Rockman Exile on romhacking.net | The current format of the site: the name and extension, then CRC32, MD5, SHA-1 and SHA-256 (only the CRC32 is read) |

# RomSieve documentation

RomSieve audits, filters and sorts ROM collections against their DAT (TOSEC, No-Intro, Redump, MAME), keeping one
release per game. It runs on Windows and Linux.

* **[User guide (English)](en/index.md)**
* **[Guide utilisateur (français)](fr/index.md)**

The interface is also available in Spanish; the guide is written in English and French.
